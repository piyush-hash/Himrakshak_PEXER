## 📋 Overview

**Himrakshak PEXER** is a comprehensive web-based emergency response platform designed to streamline communication, resource allocation, and coordination during critical situations. The platform enables quick dissemination of disaster information and facilitates efficient resource management.

### Key Features

✅ **Real-time Emergency Alerts** - Instant notification system for disaster events  
✅ **Interactive Map Visualization** - Visual representation of affected areas  
✅ **Resource Management** - Track and allocate emergency resources efficiently  
✅ **Data-Driven Insights** - Analytics dashboard for informed decision-making  
✅ **Community Engagement** - Connect emergency services with local communities  
✅ **Story-Driven Interface** - Compelling data storytelling capabilities

## 🚀 **Getting Started**

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required - works directly in browser

### Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/piyush-hash/Himrakshak_PEXER.git
   cd Himrakshak_PEXER
   ```

2. **Open in browser**
   - For static files: Open `index.md` or `index.html` in browser
   - For local development: Use Jekyll
     ```bash
     gem install jekyll bundler
     bundle exec jekyll serve
     ```

3. **Access the application**
   - Navigate to `http://localhost:4000` (if using Jekyll)
   - Or open local HTML files directly
